## About me

I'm a Software Developer at PayTic in Charlottetown, Prince Edward Island, and a contributor to [FOAM3](https://github.com/foam-foundation/foam3).

I build Flutter and Dart packages, and when a bug lives in a library I depend on, I fix it upstream instead of working around it. That has taken me into Metal and Vulkan shaders in ExecuTorch, the Flutter engine, native video renderers and CMake build hooks.

If I do something twice, I automate it. My CI ships my packages, and my AI agent workflows handle the rest.
